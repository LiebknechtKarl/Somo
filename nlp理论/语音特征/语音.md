

# 音频基本信息

</br> 常见音频格式：WAV，MP3，WMA，APE，FLAC，OGG，AAC 
</br> WAV：一种无损音频文件格式，保留了音频的全部细节，音质高。
- **优点** ：音质好、无损压缩。
- **缺点** ：文件较大。
</br> MP3：丢弃掉音频数据中对人类听觉不重要的数据，从而达到了小得多的文件大小
</br>     （其在较大的压缩率以及基本保持低音频部分不失真的情况下，以牺牲声音文件中人耳不敏感的高频部分来实现缩小文件）。
- **优点** ：文件小、兼容性好。
- **缺点** ：音质略有损失。
</br>  mp3文件，是把wav文件中一部分人耳不易听见的高频削去得到的。mp3文件转成wav文件，即把削去的部分又采样一遍，但是由于信息已经没有了，重新采样得到的都是空的。

</br>  无损：人耳听觉范围是20Hz~20kHz，根据香农采样定理，理论上来说采样率大于40kHz的音频格式都可以称之为无损格式。

```python3
from pydub import AudioSegment
import wave
import numpy as np
import matplotlib.pyplot as plt
import librosa
import librosa.display

def get_audio_info(file_path):
    # 使用 librosa 读取音频（用于后续提取 MFCC）
    y, sr = librosa.load(file_path, sr=None)

    # 使用 pydub 读取音频文件
    audio = AudioSegment.from_file(file_path)

    # 获取音频文件的基本信息
    sample_rate = audio.frame_rate
    channels = audio.channels
    sample_width = audio.sample_width
    duration = len(audio) / 1000.0  # 转换为秒

    # 打印基本信息
    print(f"采样率: {sample_rate} Hz")
    print(f"声道数: {channels}")
    print(f"采样宽度: {sample_width} bytes")
    print(f"音频时长: {duration:.2f} seconds")

    # 获取 PCM 数据
    pcm_data = np.array(audio.get_array_of_samples())
    print(f'PCM数据范围: {min(pcm_data)} ~ {max(pcm_data)}，动态范围: {float(np.max(pcm_data)) - float(np.min(pcm_data))}')

    # 如果是立体声，将声道分开
    if channels == 2:
        pcm_data = np.reshape(pcm_data, (-1, 2))

    # 绘制波形图
    plt.figure(figsize=(10, 4))
    if channels == 2:
        plt.plot(pcm_data[:, 0], label='Left Channel')
        plt.plot(pcm_data[:, 1], label='Right Channel')
        plt.legend()
    else:
        plt.plot(pcm_data)
    plt.title('音频波形图')
    plt.xlabel('样本索引')
    plt.ylabel('幅度')
    plt.tight_layout()
    plt.show()

    # 使用 wave 库获取更多详细信息
    with wave.open(file_path, 'rb') as wf:
        print(f"音频编码格式: {wf.getcomptype()}")
        print(f"音频封装格式: {wf.getsampwidth() * 8}-bit PCM")

    # 计算 MFCC 并绘图（可选）
    mfccs = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
    plt.figure(figsize=(10, 4))
    librosa.display.specshow(mfccs, x_axis='time', sr=sr)
    plt.colorbar()
    plt.title('MFCC')
    plt.tight_layout()
    plt.show()

if __name__ == '__main__':
    # 调用函数并传入音频文件路径
    get_audio_info('./alert.wav')
```

## 脉冲编码调制(Pulse Code Modulation, PCM)
</br>  脉冲编码调制(Pulse Code Modulation, PCM)是语音信号的重要编码方式之一。语音编码是将模拟信号转为数字信号的语音通信技术,分为波形编码、参量编码和混合编码等类型。波形编码针对语音波形进行,在降低量化样本比特数的同时保持了良好的语音质量。
</br>  PCM编码就是一种波形编码方法,通过每隔一段时间对模拟语音信号采样,将其取整量化,用二进制码表示抽样量化的幅值,实现将语音数字化的编码调制。

## 采样率
</br>  外界的声音在数字设备转化成由0、1表示的数字信号后被储存下来。数字信号都是离散的，所以采样率是指一秒钟采样的次数，采样率越高，还原的声音也就越真实。由于人耳听觉范围是20Hz~20kHz，根据香农采样定理(也叫奈奎斯特采样定理)，理论上来说采样率大于40kHz的音频格式都可以称之为无损格式。
</br>  现一般的专业设备的采样频率为44.1kHz。44.1kHz是专业音频中的最低采样率，也叫“CD级音质”(22.05kHz采样率为广播级音质)。常用的音频采样频率有：8kHz、11.025kHz、22.05kHz、16kHz、37.8kHz、44.1kHz、48kHz、96kHz、192kHz等。
</br>  香农采样定理(也叫奈奎斯特采样定理):为了不失真地恢复模拟信号，采样频率应该大于等于模拟信号频谱中最高频率的2倍。
</br>  图1蓝色代表模拟音频信号，红色的点代表采样得到的量化数值。采样频率越高，红色的间隔就越密集，记录这一段音频信号所用的数据量就越大，同时音频质量也就越高。

## 声道(Sound Channel)
</br>  声道数：由于音频的采集和播放是可以叠加的，因此，可以同时从多个音频源采集声音，并分别输出到不同的扬声器，故声道数一般表示声音录制时的音源数量或回放时相应的扬声器数量。单声道（Mono）和双声道（Stereo）比较常见，顾名思义，前者的声道数为1，后者为2。

</br>  四声道：四声道环绕规定了4个发音点，前左、前右，后左、后右，听众则被包围在这中间。

## 预加重
</br>  预加重是语音信号处理的前提，主要目的是提升语音信号中的高频分量。
</br>  在语音信号中，提升高频分量的目的主要是因为高频分量（即辅音）包含了更多的信息，而元音的频率普遍较低。功率谱随频率的增加而减小，其大部分能量集中在低频范围内。这就造成消息信号高频端的信噪比可能降到不能容忍的程度。
</br>  预加重保持信号的低频部分不变，提升信号的高频部分；而去加重衰减信号的低频部分，保持高频部分。预加重/去加重的目的都是提升信号中高频部分的能量，以补偿信道对高频部分衰减过大。预加重一般采用的是一阶高通滤波器：
$$H(z) = 1-\mu z^{-1} $$
其中， $$\mu z^{-1}$$ 的取值一般接近于1。

## 分帧
</br>  将N个采样点集合成一个观测单位，称为帧。通常情况下N的值为256或512，涵盖的时间约为20~30ms左右。
</br>  为了避免相邻两帧的变化过大，因此会让两相邻帧之间有一段重叠区域，此重叠区域包含了M个取样点，通常M的值约为N的1/2或1/3。
</br>  通常语音识别所采用语音信号的采样频率为8KHz或16KHz，以8KHz来说，若帧长度为256个采样点，则对应的时间长度是256/8000×1000=32ms。

## 加窗
</br>  语音在长范围内是不停变动的，没有固定的特性无法做处理，所以将每一帧代入窗函数，窗外的值设定为0，其目的是消除各个帧两端可能会造成的信号不连续性。常用的窗函数有方窗、汉明窗和汉宁窗等，根据窗函数的频域特性，常采用汉明窗。
</br>  汉明窗（Hamming Window）是一种常用的窗函数，用于信号处理和频谱分析中。窗函数的作用是减少频谱泄漏，提高频谱分析的精度。汉明窗是通过将信号截断并使其在窗口的两端平滑地衰减到零来实现的。
</br>  汉明窗的数学公式如下：
$$\omega (n) = 0.54 - 0.46 cos(\frac{2\pi n}{N-1}  )$$
其中：
</br>    $$\omega (n)$$是窗函数在第 n 个采样点的值。
</br>  &nbsp;&nbsp;&nbsp;&nbsp;     N 是窗函数的长度(采样点数)
</br>    &nbsp;&nbsp;&nbsp;&nbsp;     n 是采样点的索引，范围为 0≤n≤N−1。
</br>    汉明窗的作用
</br>    &nbsp;&nbsp;&nbsp;&nbsp;   1. 减少频谱泄漏：在频谱分析中，信号的截断会导致频谱泄漏。汉明窗通过在窗口的两端引入平滑的衰减，减少了这种泄漏。
</br>    &nbsp;&nbsp;&nbsp;&nbsp;   2. 提高分辨率：通过减少频谱泄漏，汉明窗可以提高频谱分析的分辨率，使频谱峰值更加明显。

```
# 生成汉明窗
def hamming_window(length):
    n = np.arange(length)
    window = 0.54 - 0.46 * np.cos(2 * np.pi * n / (length - 1))

# 添加噪声
def add_noise(signal, noise_level=0.1):
    noise = np.random.normal(0, noise_level, len(signal))
    return signal + noise

# 计算频谱
def compute_spectrum(signal, sr=1000):

# 计算原始噪声信号和应用汉明窗后信号的频谱

# 应用汉明窗后的信号

plt.plot(windowed_signal)

plt.ylabel("幅度")

# 原始带噪信号的频谱

plt.plot(freq_noisy[:len(freq_noisy)//2], spectrum_noisy[:len(spectrum_noisy)//2])
```

# 时频特征简介

## 功率谱（Power Spectrum）
</br>  功率谱描述了信号在各个频率上的能量分布。它通过傅里叶变换将信号从时域转换到频域，计算每个频率分量的幅度平方（能量）。
</br>  功率谱表示信号在每个频率上的能量大小，但它是整个信号的全局频域表示，没有时间信息。
</br>  ![输入图片说明](%E8%AF%AD%E9%9F%B3%E5%9B%BE%E7%89%87/4.png)

```
import librosa
import librosa.display
import numpy as np
import matplotlib.pyplot as plt

# === 1. 加载音频 ===
file_path = 'alert.wav'  # 替换成你的音频路径
y, sr = librosa.load(file_path, sr=None)  # 保留原采样率

# === 2. 计算傅里叶变换 (整段音频的功率谱) ===
fft_result = np.fft.fft(y)
fft_freqs = np.fft.fftfreq(len(y), d=1/sr)

# 只取正频率部分
pos_mask = fft_freqs >= 0
fft_freqs = fft_freqs[pos_mask]
fft_power = np.abs(fft_result)**2
fft_power = fft_power[pos_mask]

# === 3. 计算频谱图 (Spectrogram) ===
stft_result = librosa.stft(y, n_fft=1024, hop_length=256)
spectrogram = np.abs(stft_result)**2
log_spectrogram = librosa.power_to_db(spectrogram)

# === 4. 画图对比 ===
plt.figure(figsize=(14, 6))

# --- 左图：功率谱 ---
plt.subplot(1, 2, 1)
plt.plot(fft_freqs, fft_power, color='green')
plt.title("Power Spectrum")
plt.xlabel("Frequency (Hz)")
plt.ylabel("Power")
plt.grid(True)

# --- 右图：频谱图 ---
plt.subplot(1, 2, 2)
librosa.display.specshow(log_spectrogram, sr=sr, hop_length=256, x_axis='time', y_axis='log')
plt.colorbar(format='%+2.0f dB')
plt.title("Spectrogram (Log Power)")
plt.tight_layout()

plt.show()
```

```
import librosa
import librosa.display
import numpy as np
import matplotlib.pyplot as plt

# 加载音频文件
audio_path = 'example.wav'  # 替换为你的音频文件路径
y, sr = librosa.load(audio_path, sr=None)

# 计算短时傅里叶变换（STFT）

plt.figure(figsize=(12, 6))

plt.colorbar(format='%+2.0f dB')
plt.title('语音频谱图')
plt.xlabel('时间 (秒)')
plt.ylabel('频率 (Hz)')

# 平均功率谱
plt.subplot(2, 1, 2)
mean_power_spectrum = np.mean(power_spectrum, axis=1)
plt.plot(mean_power_spectrum)
plt.title('平均功率谱')
plt.xlabel('频率 (Hz)')
plt.ylabel('功率')

plt.tight_layout()
plt.show()
```

## 梅尔滤波器组(Mel-filter banks)
</br>    公式: 梅尔谱图 = 频谱能量 × Mel 滤波器组
</br>    耳蜗实质上的作用相当于一个滤波器组，耳蜗的滤波作用是在对数频率尺度上进行的，在1000HZ以下为线性尺度，1K HZ以上为对数尺度，使得人耳对低频信号敏感，高频信号不敏感
</br>    例如，人们可以比较容易地发现500和1000Hz的区别，但很难发现7500和8000Hz的区别。
</br>    根据这一原则，制作Ｍel频率滤波器组,Ｍel滤波器组的在靠近低频出越密集，越靠近高频出，滤波器越稀疏
</br>    Mel(三角形)滤波器组： 梅尔滤波器通常由一组三角形滤波器组成，每个滤波器在频率上重叠，且其中心频率按照梅尔频率分布。这种设计使得在低频区域，滤波器的带宽较宽，而在高频区域，滤波器的带宽较窄，更符合人类听觉系统的特性。
</br>  ![输入图片说明](%E8%AF%AD%E9%9F%B3%E5%9B%BE%E7%89%87/9.png)

</br>    将每个滤波器分别和语音频谱图（Spectrogram）进行点乘，获得的结果即梅尔谱图

## MFCC（Mel Frequency Cepstral Coefficients）
MFCC是对 Mel 频谱图做对数压缩 + 离散余弦变换(DCT)得到的特征向量，起到保留整体包络，去除细节的效果
$$MFCC_{k} = \sum_{m=1}^{M}logM(m,t)\cdot cos[\frac{\pi k}{m} (m-0.5)  ]   $$

优点：
- 更紧凑、鲁棒的声学特征表示
- 被广泛用于语音识别、说话人识别、情感识别



|特征类型|频率尺度|维度|是否模拟人耳|常用于|&nbsp; |
| ----------- | ----------- |----------- | ----------- |----------- |----------- |
|Spectrogram|线性|高（~1025）|否|可视化、分析|高清原图：包含所有频率细节|
|Mel Spectrogram|Mel 非线性|中（~40）|是|深度学习输入、语音分析|"高清图 → 模糊处理：按人耳敏感度压缩不重要细节"|
|MFCC|Mel+DCT|低（~13）|是+压缩|传统语音识别、情感识别等|模糊图→描边轮廓：保留轮廓线条用于识别|



```
波形（时域）x(t)
   ↓ STFT（短时傅里叶变换）
频谱图 Spectrogram（线性频率）
   ↓ Mel滤波器组（频率映射）
梅尔谱 Mel Spectrogram（非线性频率）
   ↓ 对数 + DCT（离散余弦变换）
MFCC（梅尔频率倒谱系数）
```
## 其它特征

</br>  PLP（Perceptual Linear Prediction，感知线性预测）是一种比 MFCC 更贴近人耳听觉感知特性的音频特征提取方法，由 Hynek Hermansky 在 1990 年提出，主要用于语音识别、说话人识别等任务。
</br>  PLP 的设计目标是：模拟人耳的听觉系统，在处理语音信号时考虑人耳的频率分辨率、响度压缩、临界带掩蔽效应等感知特性。

</br>  CQCC 是一种通过 Constant-Q Transform（CQT）+ 倒谱分析（如 DCT） 获得的音频特征。
</br>  它借鉴了 MFCC 的思想，但在频谱分析上，使用了更符合人耳音高感知特性的 CQT，而不是线性频率划分的FFT/Mel 滤波器。是近年来提出的一种 语音信号特征提取方法，尤其在 说话人识别、伪造语音检测（如抗欺骗 ASV） 方面表现优异。
