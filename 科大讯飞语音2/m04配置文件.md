#### ros2 run voiceinteraction aiui_new_mic 

对应文件   somo_voice/src/voiceinteraction/src/aiui_new_mic/aiui_new_mic.cpp



```C++
#include "rclcpp/rclcpp.hpp"
#include "my_aiui.h"
using namespace std;
int main(int argc, char **argv)
{
    rclcpp::init(argc, argv);
    MyAIUI aiui_agent;
    cout << ">>>>>创建AIUI代理Agent\n" << endl;
    aiui_agent.createAgent();
    cout << ">>>>>开启AIUI交互\n" << endl;
    aiui_agent.agentStart();
    cout << ">>>>>唤醒AIUI\n" << endl;
    aiui_agent.wakeup();
    cout << ">>>>>请输入指令，q退出\n" << endl;
    aiui_agent.readCmd();
    rclcpp::shutdown();
    return 0;
}
```
这个节点的主要功能是通过控制台接受用户输入的指令来控制AIUI代理的行为。
初始化ROS 2节点并与一个名为MyAIUI的自定义AIUI类进行交互。  main函数里前几行是创建aiui
关键在于     aiui_agent.readCmd();        该行跳转   somo_voice/src/voiceinteraction/src/aiui_new_mic/my_aiui.cpp 大概860行

```C++
void MyAIUI::readCmd()
{
    sleep(7);
    rclcpp::Node::SharedPtr node1(p_node->speak_node);
    rclcpp::Node::SharedPtr node2(p_node->speakend_node);
    rclcpp::executors::MultiThreadedExecutor executor;
    executor.add_node(node1);
    executor.add_node(node2);
    executor.spin();
    rclcpp::shutdown();
}
// 初始化了两个ROS 2节点 speak_node 和 speakend_node，并将它们添加到了一个多线程执行器 executor 中。
```
