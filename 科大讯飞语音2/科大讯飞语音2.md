- 在home目录下新建文件夹humanoid_ws
- 解压文件到humanoid_ws
- 将 src/awake.pcm 和 awake.wav 复制到 src 同级目录下
- 查看创建 -> 帐号流程:修改appid和对应lib*文件
- 安装依赖
	- sudo apt-get install libasound2-dev
	- sudo apt-get install mplayer
	- pip install pyaudio
	- pip install tqdm
	- sudo apt-get install pulseaudio 
	- sudo apt-get install pavucontrol
- 进行编译
	- cd humanoid_ws
	- colcon build 
	- source install/local_setup.bash
- 单个节点测试
	- ros2 run humanoid_voice awaken_record # 麦克风录制音频节点
		- 打开 src同级目录下.wav文件 播放是否有声音

- launch 测试

```
C++
public：public访问控制修饰符指定的成员是公共成员，在类的内部和外部都可以被访问。这意味着类的外部代码可以直接访问公共成员。
private：private访问控制修饰符指定的成员是私有成员，在类的内部可以被访问，但在类的外部不能直接访问私有成员。只有类的成员函数可以访问私有成员。
```
