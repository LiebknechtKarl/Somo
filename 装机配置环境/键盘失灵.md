明白了，你现在想把 Ubuntu 的输入法框架从 **IBus** 直接换成 **Fcitx**，这样可以更稳定，避免键盘失灵和延迟的问题。我帮你整理了一套完整的步骤，让你能一次性完成切换。

---

## **1. 安装 Fcitx 框架和中文输入法**

先安装 Fcitx 主程序和中文输入法（如 Google Pinyin 或百度拼音）：

```bash
sudo apt update
sudo apt install fcitx fcitx-config-gtk fcitx-ui-classic fcitx-googlepinyin
```

如果你更想用百度拼音：

```bash
sudo apt install fcitx fcitx-baidupinyin
```

这会安装 Fcitx 主框架 + 输入法配置工具 + 中文输入法。

---

## **2. 设置 Fcitx 为默认输入法**

Ubuntu 默认用 IBus，我们需要改成 Fcitx。

### 方式 1：图形界面设置（推荐）

1. 打开 **系统设置 → 地区与语言**（或 **Language Support**）。
2. 在 **键盘输入法系统**（Keyboard input method system）里，改成 **Fcitx**。
3. 重新登录或重启。

### 方式 2：命令行修改

在终端执行：

```bash
im-config -n fcitx
```

然后重启系统。

---

## **3. 配置 Fcitx 输入法**

重启后，按 **Ctrl+Space** 可能会弹出 Fcitx 配置界面。
如果没有，手动打开：

```bash
fcitx-configtool
```

在里面：

* **添加输入法**：选择 *Google Pinyin* 或 *Baidu Pinyin*。
* 可以设置快捷键、主题等。

---

## **4. 移除 IBus（可选）**

如果你确认 Fcitx 没问题，可以卸载 IBus：

```bash
sudo apt remove ibus ibus-pinyin ibus-libpinyin
```

这样系统只会使用 Fcitx。

---

## **5. 确认 Fcitx 生效**

* 在终端输入 `echo $GTK_IM_MODULE`
  如果输出 `fcitx`，说明切换成功。
* 在文本编辑器里按 **Ctrl+Space** 切换中英文，确保输入法可用。

---

## **6. 常用快捷键**

* **Ctrl+Space**：切换中英文
* **Ctrl+Shift**：切换输入法
* **Fcitx 配置界面**：`fcitx-configtool`
